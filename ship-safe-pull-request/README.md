# Ship Safe Pull Request

## Что это

`Ship Safe Pull Request` — скилл для Codex и Claude Code, который помогает безопасно довести изменение от задачи до готового pull request.

## Зачем

Скилл фиксирует единый рабочий процесс:

- согласовывает план до начала работы;
- изолирует изменения в отдельном worktree и ветке;
- не затрагивает чужие и незакоммиченные файлы;
- запускает доступные проверки;
- создаёт понятный PR и останавливается перед merge до явного разрешения.

## Что требуется для работы

- Codex или Claude Code с поддержкой скиллов;
- проект под управлением Git;
- GitHub-репозиторий и доступ к push и созданию PR;
- подключённый GitHub-аккаунт или авторизованный GitHub CLI;
- команды проекта для тестов, lint, typecheck или сборки, если они есть.

Vercel необязателен. Если проект подключён к Vercel, скилл находит и показывает PR-preview. Без Vercel результат подтверждается доступными проверками проекта.

## Как показывает результат

Отчёт начинается с результата. Затем идут проект, ветка и коммит, статус проверок, ссылки для ревью и следующее действие.

При успехе подробности проверок скрываются. Красный маркер 🔴 используется только для ошибок и рисков. Строка «Ревью» всегда остаётся без эмоджи.

## Как подключить

Попросите Codex установить скилл из GitHub:

```text
Установи скилл из https://github.com/venyavekk-dev/deveq/tree/main/ship-safe-pull-request
```

Или скопируйте папку вручную:

- Codex — `~/.codex/skills/ship-safe-pull-request/`;
- Claude Code для всех проектов — `~/.claude/skills/ship-safe-pull-request/`;
- Claude Code для одного проекта — `<project>/.claude/skills/ship-safe-pull-request/`.

Затем укажите скилл в задаче:

```text
Используй $ship-safe-pull-request, чтобы внести изменение и подготовить PR.
```

## Что в папке

```text
ship-safe-pull-request/
├── README.md
├── SKILL.md
└── agents/
    └── openai.yaml
```

- `README.md` — короткая инструкция для человека;
- `SKILL.md` — правила работы агента;
- `agents/openai.yaml` — метаданные для интерфейса Codex.
