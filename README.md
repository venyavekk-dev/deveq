# deveq

Это мой набор скиллов и инструментов для работы над проектами с Codex.

Здесь хранятся общие правила совместной работы, повторяемые процессы и небольшие инструменты, которые помогают аккуратно планировать изменения, проверять результат и безопасно доставлять работу через pull request.

## Состав

- [`AGENTS.md`](./AGENTS.md) — мои общие правила работы над проектами.
- [`ship-safe-pull-request`](./ship-safe-pull-request/) — скилл для безопасной доставки небольших, целевых изменений через pull request.

## Использование

Скопируйте нужную папку скилла в каталог скиллов Codex или подключите этот репозиторий удобным для вашей среды способом. Перед использованием проверьте правила внутри скилла и адаптируйте соглашения об именовании веток, проверках и публикации под свой проект.
